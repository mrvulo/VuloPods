# VuloPods v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eine treiberfreie Windows-Tray-App, die AirPods-Akkustände, Deckel- und Ohr-Status aus BLE-Werbepaketen liest, ein Popup beim Deckelöffnen zeigt und Medien beim Herausnehmen pausiert.

**Architecture:** `VuloPods.Core` (Klassenbibliothek) enthält Parser, Zustandslogik, Auto-Pause-Logik und die WinRT-Anbindungen (LE-Scanner, Mediensteuerung). `VuloPods.App` (WPF) enthält nur Tray, Popup und Verdrahtung. `VuloPods.Tests` (xUnit) testet alle reinen Logikbausteine mit injizierter Zeit (`TimeProvider`).

**Tech Stack:** .NET 8 SDK 8.0.425, C# 12, WPF, WinRT (`Windows.Devices.Bluetooth.Advertisement`, `Windows.Media.Control`), H.NotifyIcon.Wpf, xUnit, Microsoft.Extensions.TimeProvider.Testing.

Spec: `docs/superpowers/specs/2026-09-13-vulopods-v1-design.md`

namespace VuloPods.Core.Models;

public enum AirPodsModel
{
    Unknown,
    AirPods1,
    AirPods2,
    AirPods3,
    AirPods4,
    AirPods4Anc,
    AirPodsPro,
    AirPodsPro2,
    AirPodsPro3,
    AirPodsMax,
}

public static class AirPodsModels
{
    // Modell-IDs aus Byte 3-4 des Proximity-Pairing-Pakets (Big Endian).
    // Quellen: OpenPods PodsStatus.java, librepods. Unverifizierte IDs werden
    // beim Aufzeichnen eigener Pakete bestätigt (siehe README).
    public static AirPodsModel FromId(ushort modelId) => modelId switch
    {
        0x0220 => AirPodsModel.AirPods1,
        0x0F20 => AirPodsModel.AirPods2,
        0x1320 => AirPodsModel.AirPods3,
        0x1920 => AirPodsModel.AirPods4,
        0x1B20 => AirPodsModel.AirPods4Anc,
        0x0E20 => AirPodsModel.AirPodsPro,
        0x1420 => AirPodsModel.AirPodsPro2,
        0x2420 => AirPodsModel.AirPodsPro2,
        0x2720 => AirPodsModel.AirPodsPro3,
        0x0A20 => AirPodsModel.AirPodsMax,
        0x1F20 => AirPodsModel.AirPodsMax,
        _ => AirPodsModel.Unknown,
    };

    public static string DisplayName(AirPodsModel model) => model switch
    {
        AirPodsModel.AirPods1 => "AirPods (1. Gen)",
        AirPodsModel.AirPods2 => "AirPods (2. Gen)",
        AirPodsModel.AirPods3 => "AirPods (3. Gen)",
        AirPodsModel.AirPods4 => "AirPods 4",
        AirPodsModel.AirPods4Anc => "AirPods 4 (ANC)",
        AirPodsModel.AirPodsPro => "AirPods Pro",
        AirPodsModel.AirPodsPro2 => "AirPods Pro (2. Gen)",
        AirPodsModel.AirPodsPro3 => "AirPods Pro (3. Gen)",
        AirPodsModel.AirPodsMax => "AirPods Max",

CaseBattery, bool LeftCharging, bool RightCharging, bool CaseCharging, bool LeftInEar, bool RightInEar, bool BothInCase, bool LidOpen, int LidOpenCounter)`; `static AirPodsAdvertisement? ProximityPairingParser.Parse(ReadOnlySpan<byte> manufacturerData)`; `const ushort ProximityPairingParser.AppleCompanyId = 0x004C`

Byte-Layout (Bytes **nach** der Company-ID, Byte 0 = 0x07). Quelle: AirPodsDesktop `AppleCP.h` und OpenPods `PodsStatus.java`, beide identisch:

| Byte | Bedeutung |
|---|---|
| 0 | 0x07 Pakettyp |
| 1 | 0x19 Restlänge |
| 2 | 0x01 |
| 3–4 | Modell-ID Big Endian |
| 5 | Bit 1: sendender Pod („curr“) im Ohr; Bit 2: beide Pods im Case; Bit 3: anderer Pod („anot“) im Ohr; Bit 5: curr ist der **linke** Pod (sonst der rechte) |
| 6 | Bits 0–3: Akku curr; Bits 4–7: Akku anot. 0–9 → ×10 %, 0xA–0xE → 100 %, 0xF → unbekannt |
| 7 | Bits 0–3: Akku Case; Bit 4: curr lädt; Bit 5: anot lädt; Bit 6: Case lädt |
| 8 | Bits 0–2: Lid-Counter; Bit 3: Deckel **geschlossen** |

using VuloPods.Core.Bluetooth;
using VuloPods.Core.Models;

namespace VuloPods.Tests;

public class ProximityPairingParserTests
{
    // Baut ein 27-Byte-Paket (ohne Company-ID) mit frei wählbaren Statusbytes.
    internal static byte[] Packet(ushort model, byte status, byte battery, byte charging, byte lid)
    {
        var p = new byte[27];
        p[0] = 0x07; p[1] = 0x19; p[2] = 0x01;
        p[3] = (byte)(model >> 8); p[4] = (byte)(model & 0xFF);
        p[5] = status; p[6] = battery; p[7] = charging; p[8] = lid;
        return p;
    }

    [Fact]
    public void Parses_LeftIsCurrent_BothInEar()
    {
        // status 0x2A = Bit5 (curr = links) | Bit3 (anot im Ohr) | Bit1 (curr im Ohr)
        // battery 0x78 = curr(links)=8 → 80 %, anot(rechts)=7 → 70 %
        // charging 0x05 = Case 50 %, nichts lädt
        var adv = ProximityPairingParser.Parse(Packet(0x1420, 0x2A, 0x78, 0x05, 0x00));

        Assert.NotNull(adv);
        Assert.Equal(AirPodsModel.AirPodsPro2, adv.Model);
        Assert.Equal(0x1420, adv.ModelId);
        Assert.Equal(80, adv.LeftBattery);
        Assert.Equal(70, adv.RightBattery);
        Assert.Equal(50, adv.CaseBattery);
        Assert.True(adv.LeftInEar);
        Assert.True(adv.RightInEar);
        Assert.False(adv.BothInCase);
        Assert.False(adv.LeftCharging);
        Assert.False(adv.RightCharging);
        Assert.False(adv.CaseCharging);
    }

    [Fact]
    public void Parses_RightIsCurrent_InCase_Charging_LidClosed()
    {
        // status 0x04 = Bit5 nicht gesetzt (curr = rechts), Bit2 beide im Case
        // battery 0x9A = curr(rechts)=0xA → 100 %, anot(links)=9 → 90 %
        // charging 0x7F = Case unbekannt (0xF), curr lädt, anot lädt, Case lädt
        // lid 0x0B = Bit3 geschlossen, Counter 3
        var adv = ProximityPairingParser.Parse(Packet(0x0E20, 0x04, 0x9A, 0x7F, 0x0B));

        Assert.NotNull(adv);
        Assert.Equal(AirPodsModel.AirPodsPro, adv.Model);
        Assert.Equal(100, adv.RightBattery);
        Assert.Equal(90, adv.LeftBattery);
        Assert.Null(adv.CaseBattery);
        Assert.True(adv.RightCharging);
        Assert.True(adv.LeftCharging);
        Assert.True(adv.CaseCharging);
        Assert.True(adv.BothInCase);
        Assert.False(adv.LeftInEar);
        Assert.False(adv.RightInEar);
        Assert.False(adv.LidOpen);
        Assert.Equal(3, adv.LidOpenCounter);
    }

    [Fact]
    public void Parses_LidOpen_WithCounter()
    {
        var adv = ProximityPairingParser.Parse(Packet(0x1420, 0x24, 0x55, 0x08, 0x05));
        Assert.NotNull(adv);
        Assert.True(adv.LidOpen);
        Assert.Equal(5, adv.LidOpenCounter);
    }

    [Fact]
    public void Parses_OnlyRightInEar_WhenRightIsCurrent()
    {
        // curr = rechts (Bit5 aus), Bit1 curr im Ohr → rechts im Ohr, links nicht
        var adv = ProximityPairingParser.Parse(Packet(0x1420, 0x02, 0x55, 0x05, 0x00));
        Assert.NotNull(adv);
        Assert.True(adv.RightInEar);
        Assert.False(adv.LeftInEar);
    }

    [Theory]
    [InlineData(0x0, 0)]
    [InlineData(0x9, 90)]
    [InlineData(0xA, 100)]
    [InlineData(0xC, 100)]
    public void BatteryNibble_MapsToPercent(int nibble, int expected)
    {
        var battery = (byte)((nibble << 4) | nibble);
        var adv = ProximityPairingParser.Parse(Packet(0x1420, 0x20, battery, (byte)nibble, 0x00));
        Assert.NotNull(adv);
        Assert.Equal(expected, adv.LeftBattery);

    private const byte ProximityPairingType = 0x07;
    private const int MinLength = 11;

    /// <param name="data">Herstellerdaten ohne die zwei Bytes Company-ID; data[0] muss 0x07 sein.</param>
    public static AirPodsAdvertisement? Parse(ReadOnlySpan<byte> data)
    {
        if (data.Length < MinLength || data[0] != ProximityPairingType)
            return null;

        var modelId = (ushort)((data[3] << 8) | data[4]);
        var status = data[5];
        var battery = data[6];
        var chargingAndCase = data[7];
        var lid = data[8];

        var currentIsLeft = (status & 0x20) != 0;
        var currentInEar = (status & 0x02) != 0;
        var otherInEar = (status & 0x08) != 0;
        var bothInCase = (status & 0x04) != 0;

        var currentBattery = ToPercent(battery & 0x0F);
        var otherBattery = ToPercent(battery >> 4);
        var caseBattery = ToPercent(chargingAndCase & 0x0F);

        var currentCharging = (chargingAndCase & 0x10) != 0;
        var otherCharging = (chargingAndCase & 0x20) != 0;
        var caseCharging = (chargingAndCase & 0x40) != 0;

        var lidOpen = (lid & 0x08) == 0;
        var lidCounter = lid & 0x07;

        return new AirPodsAdvertisement(
            ModelId: modelId,
            Model: AirPodsModels.FromId(modelId),
            LeftBattery: currentIsLeft ? currentBattery : otherBattery,
            RightBattery: currentIsLeft ? otherBattery : currentBattery,
            CaseBattery: caseBattery,
            LeftCharging: currentIsLeft ? currentCharging : otherCharging,
            RightCharging: currentIsLeft ? otherCharging : currentCharging,
            CaseCharging: caseCharging,
            LeftInEar: currentIsLeft ? currentInEar : otherInEar,
            RightInEar: currentIsLeft ? otherInEar : currentInEar,
            BothInCase: bothInCase,
            LidOpen: lidOpen,
            LidOpenCounter: lidCounter);
    }

    private static int? ToPercent(int nibble) => nibble switch
    {
        0xF => null,
        >= 0xA => 100,
        _ => nibble * 10,
    };
}

namespace VuloPods.Core.Logging;

public static class Log
{
    private static readonly object Gate = new();
    private static string? _directory;
    private static long _maxBytes = 1_000_000;

    public static string? FilePath { get; private set; }

    public static void Initialize(string directory, long maxBytes = 1_000_000)
    {
        lock (Gate)
        {
            Directory.CreateDirectory(directory);
            _directory = directory;
            _maxBytes = maxBytes;
            FilePath = Path.Combine(directory, "log.txt");
        }
    }

    public static void Shutdown()
    {
        lock (Gate)
        {
            _directory = null;
            FilePath = null;
        }
    }

    public static string DefaultDirectory =>
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "VuloPods");

    public static void Info(string message) => Write("INFO", message);
    public static void Debug(string message) => Write("DEBUG", message);

    public static void Error(string message, Exception? exception = null) =>
        Write("ERROR", exception is null ? message : $"{message}: {exception}");

    private static void Write(string level, string message)
    {
        lock (Gate)
        {
            if (FilePath is null || _directory is null) return;
            try
            {
                RotateIfNeeded();
                File.AppendAllText(FilePath,
                    $"{DateTimeOffset.Now:yyyy-MM-dd HH:mm:ss.fff} [{level}] {message}{Environment.NewLine}");
            }
            catch (IOException)
            {
                // Logging darf die App nie zum Absturz bringen.
            }
            catch (UnauthorizedAccessException)
            {
            }
        }
    }

    private static void RotateIfNeeded()
    {
        var info = new FileInfo(FilePath!);
        if (!info.Exists || info.Length < _maxBytes) return;
        File.Move(FilePath!, Path.Combine(_directory!, "log.1.txt"), overwrite: true);
    }
}

```csharp
using VuloPods.Core.Models;

namespace VuloPods.Core.Bluetooth;

public sealed class AirPodsStateStore : IDisposable
{
    public const short MinRssi = -75;
    public const short TakeoverMarginDb = 10;
    public const int TakeoverPackets = 5;
    public static readonly TimeSpan LostTimeout = TimeSpan.FromSeconds(30);

    private readonly object _gate = new();
    private readonly TimeProvider _time;
    private readonly ITimer _timeoutTimer;
    private ushort _challengerModelId;
    private int _challengerCount;

    public AirPodsState? Current { get; private set; }

    public event Action<AirPodsState>? DeviceAppeared;
    public event Action<AirPodsState>? StateChanged;
    public event Action<AirPodsState>? LidOpened;
    public event Action<AirPodsState, AirPodsAdvertisement>? EarStateChanged;
    public event Action? DeviceLost;

    public AirPodsStateStore(TimeProvider time)
    {
        _time = time;
        _timeoutTimer = time.CreateTimer(_ => CheckTimeout(), null, TimeSpan.FromSeconds(1), TimeSpan.FromSeconds(1));
    }

    public void Push(AdvertisementReceived received)
    {
        AirPodsState? appeared = null;
        AirPodsState? changed = null;
        AirPodsState? lidOpened = null;
        (AirPodsState Next, AirPodsAdvertisement Previous)? ear = null;

        lock (_gate)
        {
            var adv = received.Advertisement;
            var next = new AirPodsState(adv, received.Rssi, received.Timestamp);
            var current = Current;

            if (current is null)
            {
                if (received.Rssi < MinRssi) return;
                Current = next;
                appeared = next;
            }
            else if (current.Advertisement.ModelId == adv.ModelId)
            {
                _challengerCount = 0;
                Current = next;
                var prev = current.Advertisement;
                if (adv != prev)
                {
                    changed = next;
                    var lidJustOpened = adv.LidOpen && !prev.LidOpen;
                    var counterChangedWhileOpen = adv.LidOpen && adv.LidOpenCounter != prev.LidOpenCounter;
                    if (lidJustOpened || counterChangedWhileOpen) lidOpened = next;
                    if (adv.LeftInEar != prev.LeftInEar || adv.RightInEar != prev.RightInEar) ear = (next, prev);
                }
            }
            else
            {
                if (received.Rssi >= MinRssi && received.Rssi >= current.Rssi + TakeoverMarginDb)
                {
                    if (_challengerModelId != adv.ModelId)
                    {
                        _challengerModelId = adv.ModelId;
                        _challengerCount = 0;
                    }
                    _challengerCount++;
                    if (_challengerCount >= TakeoverPackets)
                    {
                        _challengerCount = 0;
                        Current = next;
                        appeared = next;
                    }
                }
                else
                {
                    _challengerCount = 0;
                }
            }
        }

        if (appeared is not null) DeviceAppeared?.Invoke(appeared);
        if (changed is not null) StateChanged?.Invoke(changed);
        if (lidOpened is not null) LidOpened?.Invoke(lidOpened);
        if (ear is not null) EarStateChanged?.Invoke(ear.Value.Next, ear.Value.Previous);
    }

    private void CheckTimeout()
    {
        var lost = false;
        lock (_gate)
        {
            if (Current is not null && _time.GetUtcNow() - Current.LastSeen >= LostTimeout)
            {
                Current = null;
                _challengerCount = 0;
                lost = true;
            }
        }
        if (lost) DeviceLost?.Invoke();
    }

    public void Dispose() => _timeoutTimer.Dispose();
}

```csharp
using VuloPods.Core.Logging;

namespace VuloPods.Core.Media;

public sealed class AutoPausePolicy : IDisposable
{
    public static readonly TimeSpan Debounce = TimeSpan.FromSeconds(1);

    private enum PendingAction { None, Pause, Resume }

    private readonly object _gate = new();
    private readonly IMediaController _media;
    private readonly ITimer _timer;
    private int? _wornCount;
    private PendingAction _pending;
    private bool _wePaused;

    public AutoPausePolicy(IMediaController media, TimeProvider time)
    {
        _media = media;
        _timer = time.CreateTimer(_ => Fire(), null, Timeout.InfiniteTimeSpan, Timeout.InfiniteTimeSpan);
    }

    public void OnEarState(bool leftInEar, bool rightInEar)
    {
        var worn = (leftInEar ? 1 : 0) + (rightInEar ? 1 : 0);
        lock (_gate)
        {
            if (_wornCount is null)
            {
                _wornCount = worn;
                return;
            }
            if (worn == _wornCount) return;

            _pending = worn < _wornCount ? PendingAction.Pause : PendingAction.Resume;
            _wornCount = worn;
            _timer.Change(Debounce, Timeout.InfiniteTimeSpan);
        }
    }

    private async void Fire()
    {
        PendingAction action;
        lock (_gate)
        {
            action = _pending;
            _pending = PendingAction.None;
        }

        try
        {
            switch (action)
            {
                case PendingAction.Pause:
                    if (await _media.PauseIfPlayingAsync()) _wePaused = true;
                    break;
                case PendingAction.Resume:
                    if (_wePaused)
                    {
                        _wePaused = false;
                        await _media.ResumeAsync();
                    }
                    break;
            }
        }
        catch (Exception ex)
        {
            Log.Error("Auto-Pause fehlgeschlagen", ex);
        }
    }

    public void Dispose() => _timer.Dispose();
}

        return _manager.GetCurrentSession();
    }

    {
        var session = await GetCurrentSessionAsync();
        if (session is null) return false;
        var status = session.GetPlaybackInfo().PlaybackStatus;
        if (status != GlobalSystemMediaTransportControlsSessionPlaybackStatus.Playing) return false;
        return await session.TryPauseAsync();
    }

    {
        var session = await GetCurrentSessionAsync();
        if (session is null) return;
        await session.TryPlayAsync();
    }

```csharp
using Windows.Devices.Bluetooth.Advertisement;
using Windows.Storage.Streams;
using VuloPods.Core.Logging;
using VuloPods.Core.Models;

namespace VuloPods.Core.Bluetooth;

public enum ScannerStatus
{
    Scanning,
    BluetoothUnavailable,
}

/// <summary>Empfängt BLE-Werbepakete, filtert Apple-Herstellerdaten und liefert geparste Pakete.</summary>
public sealed class AirPodsScanner : IDisposable
{
    public static readonly TimeSpan RetryInterval = TimeSpan.FromSeconds(10);

    private readonly object _gate = new();
    private readonly ITimer _retryTimer;
    private readonly HashSet<ushort> _loggedUnknownModels = new();
    private BluetoothLEAdvertisementWatcher? _watcher;
    private bool _wantRunning;

    /// <summary>Wenn true, wird jedes geparste Paket als Hex ins Log geschrieben (zum Aufzeichnen von Testfällen).</summary>
    public bool LogRawPackets { get; set; }

    public event Action<AdvertisementReceived>? Received;
    public event Action<ScannerStatus>? StatusChanged;

    public AirPodsScanner(TimeProvider time)
    {
        _retryTimer = time.CreateTimer(_ => StartWatcher(), null, Timeout.InfiniteTimeSpan, Timeout.InfiniteTimeSpan);
    }

    public void Start()
    {
        _wantRunning = true;
        StartWatcher();
    }

    public void Stop()
    {
        _wantRunning = false;
        _retryTimer.Change(Timeout.InfiniteTimeSpan, Timeout.InfiniteTimeSpan);
        lock (_gate)
        {
            DisposeWatcher();
        }
    }

    private void StartWatcher()
    {
        if (!_wantRunning) return;
        lock (_gate)
        {
            DisposeWatcher();
            try
            {
                var watcher = new BluetoothLEAdvertisementWatcher
                {
                    ScanningMode = BluetoothLEScanningMode.Active,
                };
                watcher.Received += OnReceived;
                watcher.Stopped += OnStopped;
                watcher.Start();
                _watcher = watcher;
                Log.Info("BLE-Scanner gestartet");
            }
            catch (Exception ex)
            {
                Log.Error("BLE-Scanner konnte nicht starten", ex);
                ScheduleRetry();
                return;
            }
        }
        StatusChanged?.Invoke(ScannerStatus.Scanning);
    }

    private void DisposeWatcher()
    {
        if (_watcher is null) return;
        _watcher.Received -= OnReceived;
        _watcher.Stopped -= OnStopped;
        try { _watcher.Stop(); } catch (Exception ex) { Log.Error("BLE-Scanner Stop fehlgeschlagen", ex); }
        _watcher = null;
    }

    private void ScheduleRetry()
    {
        StatusChanged?.Invoke(ScannerStatus.BluetoothUnavailable);
        _retryTimer.Change(RetryInterval, Timeout.InfiniteTimeSpan);
    }

    private void OnStopped(BluetoothLEAdvertisementWatcher sender, BluetoothLEAdvertisementWatcherStoppedEventArgs args)
    {
        if (!_wantRunning) return;
        Log.Error($"BLE-Scanner gestoppt: {args.Error}");
        ScheduleRetry();
    }

    private void OnReceived(BluetoothLEAdvertisementWatcher sender, BluetoothLEAdvertisementReceivedEventArgs args)
    {
        try
        {
            foreach (var section in args.Advertisement.ManufacturerData)
            {
                if (section.CompanyId != ProximityPairingParser.AppleCompanyId) continue;

                var bytes = new byte[section.Data.Length];
                using (var reader = DataReader.FromBuffer(section.Data))
                {
                    reader.ReadBytes(bytes);
                }

                var adv = ProximityPairingParser.Parse(bytes);
                if (adv is null) continue;

                if (LogRawPackets)
                    Log.Debug($"RX {args.RawSignalStrengthInDBm} dBm {Convert.ToHexString(bytes)}");

                if (adv.Model == AirPodsModel.Unknown && _loggedUnknownModels.Add(adv.ModelId))
                    Log.Info($"Unbekannte Modell-ID 0x{adv.ModelId:X4}, Paket {Convert.ToHexString(bytes)}");

                Received?.Invoke(new AdvertisementReceived(adv, args.RawSignalStrengthInDBm, args.Timestamp));
            }
        }
        catch (Exception ex)
        {
            Log.Error("Fehler beim Verarbeiten eines Werbepakets", ex);
        }
    }

    public void Dispose()
    {
        Stop();
        _retryTimer.Dispose();
    }
}

```csharp
using System.ComponentModel;
using System.Runtime.CompilerServices;
using VuloPods.Core.Models;

namespace VuloPods.App;

public sealed class PopupViewModel : INotifyPropertyChanged
{
    private string _modelName = "Kein Gerät gefunden";
    private string _leftText = "–";
    private string _rightText = "–";
    private string _caseText = "–";
    private int _leftPercent;
    private int _rightPercent;
    private int _casePercent;
    private bool _leftCharging;
    private bool _rightCharging;
    private bool _caseCharging;
    private bool _leftInEar;
    private bool _rightInEar;

    public event PropertyChangedEventHandler? PropertyChanged;

    public string ModelName { get => _modelName; private set => Set(ref _modelName, value); }
    public string LeftText { get => _leftText; private set => Set(ref _leftText, value); }
    public string RightText { get => _rightText; private set => Set(ref _rightText, value); }
    public string CaseText { get => _caseText; private set => Set(ref _caseText, value); }
    public int LeftPercent { get => _leftPercent; private set => Set(ref _leftPercent, value); }
    public int RightPercent { get => _rightPercent; private set => Set(ref _rightPercent, value); }
    public int CasePercent { get => _casePercent; private set => Set(ref _casePercent, value); }
    public bool LeftCharging { get => _leftCharging; private set => Set(ref _leftCharging, value); }
    public bool RightCharging { get => _rightCharging; private set => Set(ref _rightCharging, value); }
    public bool CaseCharging { get => _caseCharging; private set => Set(ref _caseCharging, value); }
    public bool LeftInEar { get => _leftInEar; private set => Set(ref _leftInEar, value); }
    public bool RightInEar { get => _rightInEar; private set => Set(ref _rightInEar, value); }

    public void Update(AirPodsAdvertisement? adv)
    {
        if (adv is null)
        {
            ModelName = "Kein Gerät gefunden";
            LeftText = RightText = CaseText = "–";
            LeftPercent = RightPercent = CasePercent = 0;
            LeftCharging = RightCharging = CaseCharging = false;
            LeftInEar = RightInEar = false;
            return;
        }

        ModelName = AirPodsModels.DisplayName(adv.Model);
        LeftText = StatusText.Percent(adv.LeftBattery);
        RightText = StatusText.Percent(adv.RightBattery);
        CaseText = StatusText.Percent(adv.CaseBattery);
        LeftPercent = adv.LeftBattery ?? 0;
        RightPercent = adv.RightBattery ?? 0;
        CasePercent = adv.CaseBattery ?? 0;
        LeftCharging = adv.LeftCharging;
        RightCharging = adv.RightCharging;
        CaseCharging = adv.CaseCharging;
        LeftInEar = adv.LeftInEar;
        RightInEar = adv.RightInEar;
    }

    private void Set<T>(ref T field, T value, [CallerMemberName] string? name = null)
    {
        if (EqualityComparer<T>.Default.Equals(field, value)) return;
        field = value;
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));
    }
}
```

```csharp
using System.Windows;
using System.Windows.Media.Animation;
using System.Windows.Threading;
using VuloPods.Core.Models;

namespace VuloPods.App;

public partial class PopupWindow : Window
{
    public static readonly TimeSpan AutoHideDelay = TimeSpan.FromSeconds(5);
    private static readonly Duration FadeDuration = new(TimeSpan.FromMilliseconds(250));

    private readonly PopupViewModel _viewModel = new();
    private readonly DispatcherTimer _autoHide;

    public PopupWindow()
    {
        InitializeComponent();
        DataContext = _viewModel;
        _autoHide = new DispatcherTimer { Interval = AutoHideDelay };
        _autoHide.Tick += (_, _) => FadeOut();
        Deactivated += (_, _) => HideNow();
    }

    public void ShowFor(AirPodsAdvertisement? adv)
    {
        _viewModel.Update(adv);
        PositionBottomRight();
        BeginAnimation(OpacityProperty, null);
        Opacity = 1;
        Show();
        Activate();
        _autoHide.Stop();
        _autoHide.Start();
    }

    public void RefreshIfVisible(AirPodsAdvertisement? adv)
    {
        if (IsVisible) _viewModel.Update(adv);
    }

    private void PositionBottomRight()
    {
        var area = SystemParameters.WorkArea;
        Left = area.Right - Width - 12;
        Top = area.Bottom - Height - 12;
    }

    private void FadeOut()
    {
        _autoHide.Stop();
        var fade = new DoubleAnimation(1, 0, FadeDuration);
        fade.Completed += (_, _) => HideNow();
        BeginAnimation(OpacityProperty, fade);
    }

    private void HideNow()
    {
        _autoHide.Stop();
        BeginAnimation(OpacityProperty, null);
        Hide();
    }

    protected override void OnClosing(System.ComponentModel.CancelEventArgs e)
    {
        // Das Fenster wird nur versteckt, nie geschlossen; die App beendet sich über das Tray-Menü.
        e.Cancel = true;
        HideNow();
    }
}
```

`README.md`:

```markdown
# VuloPods

Windows-Tray-App für Apple AirPods: Akkustand, Deckel-Popup, Ohr-Erkennung mit Auto-Pause. Ohne Kernel-Treiber.

## Funktionen (v1)

- Akkustand von linkem Pod, rechtem Pod und Case im Tray-Tooltip (10%-Schritte)
- Popup beim Öffnen des Case-Deckels, Linksklick aufs Tray-Icon zeigt es jederzeit
- Medien pausieren, wenn ein Pod aus dem Ohr genommen wird; weiterspielen beim Einsetzen

Nicht enthalten: Geräuschmodus (ANC/Transparenz). Der braucht unter Windows einen Kernel-Treiber und ist als Teilprojekt 2 geplant.

## Bauen und starten

Voraussetzungen: Windows 10 2004 oder neuer, .NET 8 SDK, Bluetooth-LE-Adapter.

    dotnet build
    dotnet test
    dotnet run --project src/VuloPods.App

Die AirPods müssen nicht gekoppelt sein; sie müssen nur in Reichweite sein.

## Diagnose

Log: `%LocalAppData%\VuloPods\log.txt`. Mit `--dump` schreibt die App jedes empfangene AirPods-Paket als Hex ins Log:

    dotnet run --project src/VuloPods.App -- --dump

## Projektstruktur

- `src/VuloPods.Core` – Parser, Zustandslogik, Auto-Pause, WinRT-Anbindung
- `src/VuloPods.App` – WPF: Tray-Icon, Popup
- `tests/VuloPods.Tests` – xUnit
- `docs/superpowers/specs` – Design, `docs/superpowers/plans` – Implementierungsplan
```
